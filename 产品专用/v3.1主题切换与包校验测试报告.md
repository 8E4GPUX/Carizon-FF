#### 2.2.2 函数说明

**compute_md5(file_path)**
- 计算文件 MD5 哈希值
- 返回 32 位十六进制字符串
- 异常时返回空字符串

**compute_sha256(file_path)**
- 计算文件 SHA256 哈希值
- 返回 64 位十六进制字符串
- 异常时返回空字符串

**verify_checksum(file_path, expected_hash, algorithm)**
- 校验文件完整性
- 支持 md5/sha256 算法
- 返回 bool（是否匹配）
- 自动记录日志

**get_file_info(file_path)**
- 获取文件信息字典
- 包含：filename, size_bytes, size_mb, md5, sha256, modified
- 文件不存在返回空字典

### 6.2 改进建议

1. **主题配置持久化**
   ```python
   def save_preference(self):
       """保存主题偏好"""
       config = ConfigManager()
       config.set("主题", self._current)
       config.save()
   ```

2. **UI 集成**
   - 在底部操作栏添加主题切换按钮
   - 或使用快捷键（如 Ctrl+T）

3. **添加 ThemeManager 测试**
   ```python
   def test_toggle_theme():
       mgr = ThemeManager()
       mgr.set_theme("light")
       assert mgr.current == "light"
       mgr.toggle()
       assert mgr.current == "dark"
   ```
