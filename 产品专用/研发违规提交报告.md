```python
# 产品专用/monitor_window.py (违规新增)
class MonitorWindow(QMainWindow):
    """产品需求监控窗口"""
    
    def __init__(self):
        super().__init__()
        self._last_known_commits = set()
        self._init_ui()
        self._init_monitor()
    
    def _init_monitor(self):
        """初始化监控定时器"""
        # 启动定时器（2 分钟 = 120000 毫秒）
        self._timer = QTimer()
        self._timer.timeout.connect(self._check_updates)
        self._timer.start(120000)
```

### 6.2 正确提交方式

1. 在 `研发专用/ui/monitor_window.py` 添加监控窗口代码

3. 在 `docs/` 更新需求文档
