```python
AttributeError: 'QTextCharFormat' object has no attribute 'setBold'
```

### 2.2 错误原因

`QTextCharFormat` 类没有 `setBold()` 方法。这是 PyQt5 API 使用错误。

在 PyQt5 中，设置字体粗细应该使用 `setFontWeight()` 方法，而不是 `setBold()`。

### 2.3 影响范围

- 监控窗口无法启动
- 主程序启动失败（因为 main.py 中创建了 MonitorWindow 实例）
- 整个工具无法运行

## 三、修复方案

### 3.1 错误代码

```python
# monitor_window.py 第 345 行
tag_fmt.setBold(True)  # ❌ 错误：QTextCharFormat 没有 setBold 方法
```

### 3.2 正确代码

```python
# 需要导入 QFont
from PyQt5.QtGui import QFont

# 修改第 345 行
tag_fmt.setFontWeight(QFont.Bold)  # ✅ 正确：使用 setFontWeight 方法
```

### 3.3 完整修复示例

```python
def _append_log(self, tag: str, message: str):
    """添加日志"""
    cursor = self._log_output.textCursor()
    cursor.movePosition(QTextCursor.End)
    
    # 标签格式
    tag_fmt = QTextCharFormat()
    tag_fmt.setFontWeight(QFont.Bold)  # 修复：使用 setFontWeight 而不是 setBold
    tag_fmt.setForeground(QColor("#e94560"))
    
    cursor.insertText(f"[{tag}] ", tag_fmt)
    
    # 消息格式
    msg_fmt = QTextCharFormat()
    msg_fmt.setForeground(QColor("#e0e0e0"))
    cursor.insertText(message + "\n", msg_fmt)
    
    self._log_output.setTextCursor(cursor)
    self._log_output.ensureCursorVisible()
```

## 八、附录

### 8.1 PyQt5 QTextCharFormat 正确用法

```python
from PyQt5.QtGui import QTextCharFormat, QFont, QColor

# 创建格式对象
fmt = QTextCharFormat()

# 设置字体粗细（正确方式）
fmt.setFontWeight(QFont.Bold)      # 粗体
fmt.setFontWeight(QFont.Normal)    # 正常
fmt.setFontWeight(75)              # 数值方式（75 = Bold）

# 设置斜体
fmt.setFontItalic(True)

# 设置下划线
fmt.setFontUnderline(True)

# 设置颜色
fmt.setForeground(QColor("red"))

# 设置字体大小
fmt.setFontPointSize(12)
```
