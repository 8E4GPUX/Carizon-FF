## 二、发现的 Bug 列表

### Bug #1 - 【严重】导入路径错误导致程序无法启动

| 属性 | 内容 |
|------|------|
| 严重程度 | 🔴 严重（阻塞） |
| 影响范围 | 所有模块 |
| 发现位置 | 所有 .py 文件的 import 语句 |
| 问题描述 | 代码中使用了中文路径作为模块导入路径，如 `from 研发包部署.ota_deploy_tool.研发专用.utils.logger import get_logger` |
| 复现步骤 | 1. 运行 `python main.py`<br>2. 程序立即报错 `ModuleNotFoundError` |
| 预期结果 | 程序正常启动 |
| 实际结果 | 程序崩溃，无法启动 |
| 涉及文件 | main.py, deployment_engine.py, ssh_client.py, board_operator.py, transfer_manager.py, rollback_manager.py, package_classifier.py, config_manager.py, main_window.py, log_viewer.py, settings_dialog.py |
| 建议修复 | 将所有导入路径改为相对路径或正确的包名，如 `from utils.logger import get_logger` |

**示例错误代码：**
```python
# 错误（当前）
from 研发包部署.ota_deploy_tool.研发专用.utils.logger import get_logger

# 正确（建议）
from utils.logger import get_logger
```

### Bug #2 - 【严重】main.py 导入拼写错误

| 属性 | 内容 |
|------|------|
| 严重程度 | 🔴 严重（阻塞） |
| 影响范围 | 程序入口 |
| 发现位置 | main.py 第 13 行 |
| 问题描述 | `from PyQt5.QtCore import Qtl` 中 `Qtl` 应为 `Qt` |
| 复现步骤 | 1. 运行 `python main.py`<br>2. 程序报错 `ImportError: cannot import name 'Qtl'` |
| 预期结果 | 正确导入 Qt |
| 实际结果 | 程序崩溃 |
| 建议修复 | 将 `Qtl` 改为 `Qt` |

**错误代码：**
```python
# 错误（第13行）
from PyQt5.QtCore import Qtl

# 正确
from PyQt5.QtCore import Qt
```

### Bug #3 - 【中等】板端 SSH 认证方式可能不兼容

| 属性 | 内容 |
|------|------|
| 严重程度 | 🟡 中等 |
| 影响范围 | 板端连接 |
| 发现位置 | deployment_engine.py 第 444-452 行 |
| 问题描述 | 板端 SSH 连接使用固定用户名 `user`，无密码认证。如果板端需要密钥认证或不同用户名，将无法连接 |
| 复现步骤 | 1. 配置正确的板端 IP<br>2. 点击部署<br>3. 连接板端失败 |
| 预期结果 | 根据配置连接板端 |
| 实际结果 | 如果板端不支持无密码认证，连接失败 |
| 建议修复 | 1. 将板端用户名和密码加入配置项<br>2. 支持密钥认证方式 |

### Bug #4 - 【中等】传输进度回调参数不一致

| 属性 | 内容 |
|------|------|
| 严重程度 | 🟡 中等 |
| 影响范围 | 进度显示 |
| 发现位置 | transfer_manager.py 第 41 行 vs deployment_engine.py 第 229 行 |
| 问题描述 | TransferManager 的进度回调是 3 参数 `(current, total, message)`，但 DeploymentEngine 设置的是 2 参数 `(percent, message)` |
| 复现步骤 | 1. 启动部署<br>2. 观察进度回调 |
| 预期结果 | 进度正常更新 |
| 实际结果 | 可能出现参数不匹配错误 |
| 建议修复 | 统一进度回调参数格式 |

### 4.2 设计优点

1. **模块化设计**：各模块职责清晰，便于维护
2. **单例模式**：ConfigManager 和 LoggerManager 使用单例，保证全局一致性
3. **回调机制**：使用回调更新 UI 状态，解耦良好
4. **异常处理**：有完善的异常捕获和日志记录
5. **配置加密**：敏感信息加密存储，安全性好

### 4.3 待改进项

1. 导入路径需要修复
2. 部分硬编码值应提取到配置
3. 缺少单元测试
4. 缺少类型注解（部分函数）
