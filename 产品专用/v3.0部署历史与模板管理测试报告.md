#### 2.1.2 数据库设计

**deploy_records 表**
- id: 主键
- start_time: 开始时间
- end_time: 结束时间
- status: 状态（running/success/failed）
- package_count: 包数量
- packages: 包名列表（JSON）
- total_duration_sec: 总耗时
- error_message: 错误信息
- operator: 操作人
- template_name: 使用的模板
- device_ip: 设备IP
- created_at: 创建时间

**deploy_packages 表**
- id: 主键
- record_id: 关联记录ID
- package_name: 包名
- package_type: 包类型
- target_dir: 目标目录
- status: 状态
- duration_sec: 耗时
- error_message: 错误信息

**索引优化**
- idx_records_start: 按开始时间降序
- idx_records_status: 按状态查询
- idx_packages_record: 按记录ID查询包

#### 2.1.3 统计功能

**get_statistics(days)** 返回：
- total: 总部署次数
- success: 成功次数
- failed: 失败次数
- success_rate: 成功率（%）
- avg_duration_sec: 平均耗时（秒）
- daily: 每日部署统计
- pkg_type_stats: 包类型统计
