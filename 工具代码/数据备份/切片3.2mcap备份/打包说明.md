# CARIZON 数据切分工具 - 打包说明

## 环境要求

### 系统要求
- Windows 10/11 (推荐)
- Python 3.8+ 
- 至少 2GB 可用磁盘空间

### Python依赖
- customtkinter >= 5.2.0
- paramiko >= 2.11.0  
- openpyxl >= 3.1.0
- pyinstaller >= 5.13.0

## 快速打包

### Windows系统
1. 打开命令提示符或PowerShell
2. 进入项目目录：
   ```cmd
   cd "数据切分\工具代码\切片3.1.1"
   ```
3. 运行自动打包脚本：
   ```cmd
   build.bat
   ```

### Linux/macOS系统
1. 打开终端
2. 进入项目目录：
   ```bash
   cd "数据切分/工具代码/切片3.1.1"
   ```
3. 运行自动打包脚本：
   ```bash
   chmod +x build.sh
   ./build.sh
   ```

## 手动打包步骤

如果自动脚本失败，可以手动执行以下步骤：

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 清理旧文件
```bash
# Windows
rmdir /s /q build dist __pycache__

# Linux/macOS  
rm -rf build dist __pycache__
```

### 3. 执行打包
```bash
pyinstaller --clean pack_v3.2.1.spec
```

## 输出文件

打包成功后，可执行文件位于：
- **Windows**: `dist\CARIZON数据切分工具.exe`
- **Linux/macOS**: `dist\CARIZON数据切分工具`

## 常见问题

### 1. 打包失败
- 检查Python版本是否为3.8+
- 确保所有依赖已正确安装
- 检查是否有杀毒软件干扰

### 2. 可执行文件过大
- 这是正常现象，因为包含了完整的Python运行时
- 可以通过UPX压缩减小文件大小（已启用）

### 3. 运行时缺少模块
- 检查spec文件中的hiddenimports配置
- 确保所有必要的模块都已包含

### 4. 网络连接问题
- 确保目标服务器(10.22.33.86)可访问
- 检查SSH连接配置
