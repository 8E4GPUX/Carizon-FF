1. 环境准备

1.1 安装 Git

从官网下载安装：https://git-scm.com/

安装完成后，打开终端验证：

git --version

首次使用需配置用户名和邮箱：

git config --global user.name "你的名字" git config --global user.email "你的邮箱@example.com"

1.2 安装 VSCode

从官网下载安装：https://code.visualstudio.com/

1.3 克隆仓库到本地

# 将远程仓库克隆到本地（仓库地址由项目负责人提供） git clone <仓库地址> # 进入项目目录 cd <项目目录>

2. VSCode 中操作 Git

2.1 打开项目

方式一：命令行打开

code <项目目录路径>

方式二：VSCode 菜单

  • 打开 VSCode
  • 文件 → 打开文件夹...
  • 选择项目目录

2.2 源代码管理面板（Git 可视化操作）

▲ VSCode 源代码管理面板 — 左侧活动栏第三个图标（分支形状）

打开方式：

  • 快捷键：Ctrl + Shift + G
  • 或点击左侧活动栏的「源代码管理」图标

面板功能说明：

区域说明
更改已修改但未暂存的文件（M 标记）
暂存的更改已 git add 待提交的文件
消息输入框顶部输入提交信息
✓ 提交提交暂存的更改
... 更多操作推送、拉取、分支管理等

2.3 查看文件变更（Diff）

在「更改」列表中点击文件 → 右侧打开 Diff 视图。左侧为原文件，右侧为修改后文件。红色背景 = 删除行，绿色背景 = 新增行。

2.4 暂存 / 提交 / 推送

暂存文件：

  • 点击文件右侧的 + → 暂存该文件
  • 点击「更改」标题旁的 + → 暂存所有文件

提交代码：

  • 在消息输入框输入提交信息（如 fix: 修复登录超时问题）
  • 点击 ✓ 提交 按钮

推送 / 拉取：

  • 点击底部状态栏的「同步更改」按钮（循环箭头图标）
  • 或点击源代码管理面板的 ... → 推送 / 拉取

2.5 分支管理

点击 VSCode 左下角状态栏的分支名称 → 弹出分支选择框 → 选择已有分支切换，或输入新分支名创建。

▲ VSCode 分支切换 — 左下角状态栏点击分支名称

3. 常用 Git 命令（终端执行）

3.1 在哪里输入命令

方式一：VSCode 内置终端

  • 快捷键：Ctrl + `（反引号）
  • 或 终端 → 新建终端
  • 确保终端路径在项目目录下
▲ VSCode 内置终端 — 可在其中直接执行 Git 命令

方式二：系统终端

  • Windows：PowerShell / CMD
  • macOS：终端
  • Linux：终端
# 先进入项目目录 cd <项目目录路径>

3.2 基础操作

命令说明示例
git status查看当前工作区状态git status
git log --oneline查看简洁提交历史git log --oneline -10
git diff查看未暂存的变更git diff
git diff --cached查看已暂存的变更git diff --cached

3.3 提交相关

命令说明示例
git add <文件>暂存指定文件git add src/index.js
git add .暂存所有变更git add .
git commit -m "信息"提交暂存内容git commit -m "fix: 修复连接超时"
git commit -am "信息"暂存+提交一步完成git commit -am "feat: 新增用户模块"

3.4 远程同步

命令说明示例
git push推送到远程git push origin main
git pull拉取远程更新git pull origin main
git fetch获取远程信息（不合并）git fetch origin
git remote -v查看远程仓库地址git remote -v

3.5 分支操作

命令说明示例
git branch查看本地分支git branch
git branch -a查看所有分支（含远程）git branch -a
git checkout -b <分支>创建并切换分支git checkout -b feature/login
git checkout <分支>切换分支git checkout main
git merge <分支>合并分支到当前分支git merge feature/login

3.6 撤销 / 回退

命令说明示例
git restore <文件>撤销未暂存的修改git restore src/index.js
git restore --staged <文件>取消暂存git restore --staged src/index.js
git reset --soft HEAD~1撤销上次提交（保留修改）git reset --soft HEAD~1
git reset --hard HEAD~1撤销上次提交（丢弃修改）git reset --hard HEAD~1

3.7 提交信息规范

推荐使用约定式提交（Conventional Commits），格式统一、便于追溯：

<类型>: <简短描述>
类型使用场景示例
feat新功能feat: 新增用户登录功能
fix修复 Bugfix: 修复页面白屏问题
docs文档变更docs: 更新API使用说明
test测试相关test: 添加登录单元测试
chore构建/工具链chore: 升级依赖版本
refactor重构refactor: 重构数据查询逻辑
style代码格式style: 格式化代码缩进

4. 代码上传流程

4.1 首次上传（新文件）

详细步骤：

  1. 确认状态 — git status 查看哪些文件被修改/新增
  2. 暂存文件 — git add . 或 git add src/components/Button.jsx
  3. 提交到本地仓库 — git commit -m "feat: 新增按钮组件"
  4. 推送到远程仓库 — git push origin main

4.2 日常上传流程

# 1. 先拉取最新代码（避免冲突） git pull origin main # 2. 修改代码... # 3. 查看变更 git status git diff # 4. 暂存并提交 git add . git commit -m "fix: 修复XX问题" # 5. 推送到远程 git push origin main
💡 提示：推送前先拉取（git pull）可以避免大部分冲突。

4.3 VSCode 可视化上传

  1. 修改文件后，打开源代码管理面板（Ctrl + Shift + G）
  2. 查看「更改」列表中的文件，点击可查看 Diff
  3. 点击文件旁的 + 暂存
  4. 顶部输入提交信息
  5. 点击 ✓ 提交
  6. 点击底部状态栏的「同步更改」推送

5. 代码下载 / 同步流程

5.1 首次克隆（新电脑）

# 克隆仓库（仓库地址由项目负责人提供） git clone <仓库地址> # 进入目录 cd <项目目录>

5.2 拉取最新代码

# 方式一：拉取并自动合并 git pull origin main # 方式二：先获取再手动合并 git fetch origin git merge origin/main

5.3 VSCode 中同步

  • 点击底部状态栏的「同步更改」按钮（循环箭头图标）
  • 或使用快捷键：Ctrl + Shift + G → ... → 拉取

6. 新建分支与功能开发

6.1 分支命名规范

前缀说明示例
feature/新功能feature/user-login
fix/修复fix/timeout-error
docs/文档docs/api-guide
refactor/重构refactor/database-layer
hotfix/紧急修复hotfix/crash-on-startup

6.2 分支开发流程

# 1. 确保在主分支且代码最新 git checkout main git pull origin main # 2. 创建功能分支 git checkout -b feature/user-login # 3. 开发、提交... git add . git commit -m "feat: 新增用户登录功能" # 4. 推送到远程 git push origin feature/user-login # 5. 合并回主分支 git checkout main git merge feature/user-login git push origin main # 6. 可选：删除功能分支 git branch -d feature/user-login
⚠️ 注意：合并前确保功能分支已测试完毕，合并后及时删除无用分支。

7. 常见问题

Q: 推送被拒绝（push rejected）

# 原因：远程有本地没有的提交 # 解决：先拉取再推送 git pull origin main --rebase git push origin main

Q: 冲突（merge conflict）

出现 CONFLICT 提示时：

  1. 打开冲突文件（VSCode 会高亮标记）
  2. 选择保留哪个版本（当前 / 传入 / 两者都保留）
  3. 保存文件 → git add . → git commit

Q: 想撤销未提交的修改

git restore <文件名> # 撤销单个文件 git restore . # 撤销所有修改

Q: 想修改上次提交信息

git commit --amend -m "新的提交信息"

Q: 不小心把不该提交的文件暂存了

git restore --staged <文件名> # 取消暂存，保留修改

Q: 提示「fatal: not a git repository」

当前目录不是 Git 仓库，确认是否在正确的项目目录下。

Q: 想暂存当前工作去处理其他事

git stash # 暂存当前修改 git stash pop # 恢复暂存的修改
