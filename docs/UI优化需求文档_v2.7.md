## 一、需求背景

当前 UI 布局存在以下问题：
1. 左右面板比例固定（40:60），无法根据内容自适应调整
2. 部署进度表格列宽不合理，"类型"列信息价值低
3. GroupBox 标题占据额外空间，降低内容展示区域
4. 用户体验不够灵活，无法个性化调整界面布局

---

## 二、需求详情

### 2.1 🆕 左右面板可拖拽调整宽度

**需求描述**：
- 在左侧面板和右侧面板之间添加可拖拽的分隔条
- 用户可以通过拖拽分隔条调整左右面板的宽度比例
- 分隔条应有明显的视觉提示（如高亮、光标变化）

**技术方案**：
- 使用 `QSplitter` 替代当前的 `QHBoxLayout`
- 设置合理的初始比例（建议 40:60）
- 设置最小宽度限制，防止面板过窄

**验收标准**：
- [ ] 分隔条可拖拽
- [ ] 拖拽时光标变为调整大小样式
- [ ] 分隔条有明显的视觉提示
- [ ] 左右面板有最小宽度限制（建议 300px）
- [ ] 调整后布局保持正常

**预期效果**：
```
┌─────────────────┬───────────────────┐
│                 │                   │
│   左侧面板      │    右侧面板       │
│   (可调整)      │    (可调整)       │
│                 │                   │
└─────────────────┴───────────────────┘
         ↑ 可拖拽分隔条
```

### 2.2 🔄 部署进度表格列宽优化

**需求描述**：
- "耗时"列宽与"状态"列宽保持一致
- "类型"列改为显示具体的目标目录名称（如 `env_model`），而不是类型标识（如 `APP`）
- "类型"列宽度增加为原来的 2 倍（从 65px 增加到 130px）

**当前状态**：
| 列名 | 当前宽度 | 调整模式 |
|------|---------|---------|
| 包名 | 自动拉伸 | Stretch |
| 类型 | 65px | 固定 |
| 状态 | 80px | 固定 |
| 耗时 | 65px | 固定 |

**目标状态**：
| 列名 | 目标宽度 | 调整模式 | 说明 |
|------|---------|---------|------|
| 包名 | 自动拉伸 | Stretch | 保持不变 |
| 类型 | 130px | 固定 | 显示目标目录名（如 env_model） |
| 状态 | 80px | 固定 | 保持不变 |
| 耗时 | 80px | 固定 | 与状态列宽一致 |

**代码修改点**：
```python
# 当前代码（main_window.py 第 452-458 行）
self._pkg_table = QTableWidget(0, 4)
self._pkg_table.setHorizontalHeaderLabels(["包名", "类型", "状态", "耗时"])
self._pkg_table.horizontalHeader().setStretchLastSection(True)
self._pkg_table.horizontalHeader().setSectionResizeMode(0, QHeaderView.Stretch)
self._pkg_table.setColumnWidth(1, 65)   # 类型列
self._pkg_table.setColumnWidth(2, 80)   # 状态列
self._pkg_table.setColumnWidth(3, 65)   # 耗时列

# 修改后
self._pkg_table.setColumnWidth(1, 130)  # 类型列：65 → 130（2倍）
self._pkg_table.setColumnWidth(2, 80)   # 状态列：保持不变
self._pkg_table.setColumnWidth(3, 80)   # 耗时列：65 → 80（与状态列一致）
```

**数据修改点**：
```python
# 当前代码（main_window.py 第 703 行）
ti = QTableWidgetItem(info.pkg_type.upper())  # 显示 "APP"、"MCU" 等

# 修改后
ti = QTableWidgetItem(info.target_dir)  # 显示 "env_model"、"odometry" 等
```

**验收标准**：
- [ ] "耗时"列宽与"状态"列宽一致（均为 80px）
- [ ] "类型"列显示目标目录名称（如 `env_model`）
- [ ] "类型"列宽度为 130px
- [ ] 表格内容显示正常，无截断

### 2.3 🔄 板块标题移至内部

**需求描述**：
- 将 "升级包选择"、"部署进度"、"实时日志" 标题从 GroupBox 标题栏移至面板内部
- 使用内部 QLabel 作为标题，减少 GroupBox 边框占用的空间
- 优化各板块内部布局，提高空间利用率

**当前布局**：
```
┌─ 📁 升级包选择 ─────────────┐  ← GroupBox 标题栏（占用空间）
│ [选择文件] [清空]            │
│ ┌─────────────────────────┐ │
│ │ 文件列表                │ │
│ └─────────────────────────┘ │
└─────────────────────────────┘
```

**目标布局**：
```
┌──────────────────────────────┐
│ 📁 升级包选择                │  ← 内部标题（QLabel）
│ [选择文件] [清空]            │
│ ┌─────────────────────────┐ │
│ │ 文件列表                │ │
│ └─────────────────────────┘ │
└──────────────────────────────┘
```

**技术方案**：
1. 移除 QGroupBox，改用 QFrame + QVBoxLayout
2. 在面板顶部添加 QLabel 作为标题
3. 设置标题样式（字体、颜色、边距）

**代码修改点**：
```python
# 当前代码（使用 QGroupBox）
fg = QGroupBox("📁 升级包选择")
fg.setStyleSheet("""
    QGroupBox {
        font-size: 14px; color: #1565C0; font-weight: bold;
        padding-top: 18px;
    }
    QGroupBox::title { color: #1565C0; }
""")
fl = QVBoxLayout(fg)

# 修改后（使用 QFrame + QLabel）
fg = QFrame()
fg.setStyleSheet("""
    QFrame {
        background-color: white;
        border: 1px solid #e4e4e4;
        border-radius: 6px;
    }
""")
fl = QVBoxLayout(fg)
fl.setContentsMargins(10, 10, 10, 8)

# 添加内部标题
title_label = QLabel("📁 升级包选择")
title_label.setStyleSheet("""
    font-size: 14px; 
    color: #1565C0; 
    font-weight: bold;
    padding-bottom: 6px;
""")
fl.addWidget(title_label)
```

**验收标准**：
- [ ] "升级包选择" 标题在面板内部
- [ ] "部署进度" 标题在面板内部
- [ ] "实时日志" 标题在面板内部
- [ ] 标题样式统一（字体、颜色、边距）
- [ ] 面板边框样式统一
- [ ] 内部布局紧凑，无多余空白

### 2.4 🔄 内部布局优化

**需求描述**：
- 优化各板块内部间距和边距
- 统一按钮样式和大小
- 提高内容展示区域的占比

**优化点**：
1. 减少 GroupBox 边框占用的空间（约 18px padding-top）
2. 统一板块内部边距（建议 10px）
3. 优化按钮间距（建议 6px）
4. 优化表格行高（建议 28px）

**预期效果**：
- 内容展示区域增加约 15-20%
- 界面更加紧凑和专业
- 视觉层次更加清晰

### 6.2 参考设计

**QSplitter 使用示例**：
```python
from PyQt5.QtWidgets import QSplitter

# 创建分割器
splitter = QSplitter(Qt.Horizontal)
splitter.addWidget(left_panel)
splitter.addWidget(right_panel)

# 设置初始比例
splitter.setSizes([480, 720])  # 40:60 比例

# 设置最小宽度
splitter.setChildrenCollapsible(False)
left_panel.setMinimumWidth(300)
right_panel.setMinimumWidth(400)
```

## 七、产品优化建议

### 7.1 短期优化（本次实施）

1. **QSplitter 拖拽调整** - 提高布局灵活性
2. **表格列宽优化** - 提高信息展示效率
3. **标题内移** - 增加内容展示区域
4. **布局优化** - 提高空间利用率

### 7.2 中期优化（建议后续实施）

1. **面板折叠功能**
   - 允许用户折叠/展开左侧或右侧面板
   - 便于全屏查看日志或文件列表

2. **布局保存功能**
   - 保存用户的布局偏好
   - 下次启动时自动恢复

3. **主题切换**
   - 支持亮色/暗色主题
   - 支持自定义颜色方案

4. **响应式布局**
   - 根据窗口大小自动调整布局
   - 小窗口时自动切换为上下布局

### 7.3 长期优化（产品规划）

1. **多窗口模式**
   - 支持将日志查看器独立为单独窗口
   - 支持多显示器环境下分散布局

2. **插件化架构**
   - 允许用户自定义面板和内容
   - 支持第三方插件扩展

3. **云端同步**
   - 同步用户布局和配置
   - 多设备间无缝切换
